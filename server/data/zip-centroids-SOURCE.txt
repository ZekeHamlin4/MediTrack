zip-centroids.csv: the map point at the center of each US ZIP code area (ZCTA).

Used by MediTrack's "search near a ZIP" provider search (server/nearby.js). Offline; nothing is sent anywhere.

Source data: US Census Bureau, 2022 Gazetteer Files, ZIP Code Tabulation Areas (ZCTA) national file,
https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2022_Gazetteer/2022_Gaz_zcta_national.zip
(US government work, public domain).

Converted from the npm package us-zips 2022.9.1 (https://github.com/blakek/us-zips), which packages that
Census file. Only ZIP, latitude and longitude are kept (33,791 ZIP areas). Its licence follows.
